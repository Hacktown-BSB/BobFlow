# Skills recomendadas para o Bob

Estas skills foram montadas para apoiar uma solução útil para engenheiros de software durante um hackathon de 2 dias.

## Skill 1 — Engenheiro de software
Foco: arquitetura, código, boas práticas, revisão e produtividade.

## Skill 2 — Product architect
Foco: mapear dor do usuário, requisitos, riscos e prioridade.

## Skill 3 — Rapid prototype
Foco: prototipar rápido sem perder qualidade mínima.

## Skill 4 — Debug investigator
Foco: depuração, edge cases, revisão crítica e validação.

## Skill 5 — Pitch strategist
Foco: transformar solução em narrativa forte com demo e impacto.

## Como usar

- selecione uma skill por bloco da sessão;
- mantenha a entrada curta, objetiva e específica;
- peça saídas com formato fixo;
- sempre peça trade-offs e riscos antes de selecionar a melhor opção.
