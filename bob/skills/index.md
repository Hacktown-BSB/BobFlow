# Bob Skills Index

Este índice serve como guia de descoberta para o Bob. Ele permite escolher a skill correta sem gastar contexto em rodeios.

## Fluxo de decisão

1. Qual é o problema principal?
2. Qual área de TI ele pertence?
3. Qual fase do trabalho está em curso?
4. Qual skill é mais específica e útil?
