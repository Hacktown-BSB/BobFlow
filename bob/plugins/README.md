# Plugins e extensões úteis

Os plugins abaixo ajudam o Bob a operar com menos ruído e mais contexto útil durante o hackathon.

## Plugin 1 — planning-optimizer
Objetivo: transformar ideia em escopo executável em poucas rodadas.

## Plugin 2 — architecture-check
Objetivo: verificar viabilidade, dependências, riscos e simplicidade.

## Plugin 3 — validation-sprint
Objetivo: garantir que a solução tenha estações de validação e teste.

## Plugin 4 — pitch-composer
Objetivo: criar narrativa final com foco em impacto e prova de valor.

## Plugin 5 — review-gate
Objetivo: revisar segurança, robustez e qualidade antes de demo.

## Princípio
Cada plugin deve produzir um artefato útil: checklist, plano, risco, análise ou roteiro de apresentação, não apenas texto genérico.
